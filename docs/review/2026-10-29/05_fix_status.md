# 修复状态与验收边界

本文件记录审阅基线之后的源代码修改。`02_defects.md` 保留原始问题和证据，不应将其中的“当前”视为最新源码状态。构建通过只说明编译、链接与段布局成立，不能代替示波器、JTAG 寄存器读回或功率级试验。

## 已落实的配置与逻辑修复

- ADC 表按 A/B/C/D 交织步长 4 读取；A 组固定 SOC 优先级，保留 ZERO 与 PRD 两批采样；CLA Task2 改读 SOC8/9 第二采样结果。CLA 双向消息 RAM 段交换到正确地址。
- ePWM 移除对 F2837xS 保留偏移的写入，改用 TBCTL/SYNCSELECT；PV 上计数周期改为 4999，目标开关频率为 20 kHz。初始化后统一在 `StartSystem` 放行 TBCLKSYNC 和 CPU 中断。
- X-BAR 的 INPUT1/2/3/6/4/5 映射改用正确的奇数 MUX；低有效故障在各 TRIP 独立反相，INV 过流与短路分别送 DCA/DCB。软件控制故障或控制链心跳超时会锁存全部 ePWM 的 OST 并拉低驱动使能 GPIO88。软件故障跳闸后不能仅靠复位命令重新投入。
- INV 驱动在首次同半周下发占空比时会解除钳位；状态机故障改用六路硬件跳闸。并网合闸条件缺少相位/频差、相序和电流闭环，因此当前禁止 ATS 闭合时进入 INV 运行路径。
- SCI RX FIFO 中断阈值调为 1 并按 FIFO 剩余计数搬运；SPI 接收取消错误右移；CAN 标准 ID/掩码移到 ARB[28:18]；Modbus 32 位字序选择宏可正确参与预处理。看门狗计算计入固定 /512。
- Sys/INV/PV/BUS 状态迁移改为后台 1 kHz 任务，按 100 µs 节拍错开；INV 快速调制在 ZERO→CLA Task1→CPU ISR，PV PI 和 BUS 瞬时压差快照在 PRD→CLA Task2→CPU ISR，两个时隙各 20 kHz。PV 使用 ZERO 的样本，在 PRD 时隙计算；默认禁用，由系统 STARTUP/RUN 态授权，停机撤销授权。状态机计时常数按 1 ms 调用修正。

## 仍未满足设计的关键项

1. **三个独立闭环仍未完成。** INV 与 PV 现在分别占用 ZERO/PRD 两个 20 kHz 时隙；BUS 在 PRD 时隙仅更新瞬时采样，尚无平衡 PI 或 ePWM8 占空比下发。PV/INV 的实际 ISR 执行时长、两任务是否相互排队和每拍都完成，仍需板上测量。当前不能说三个闭环均已以 20 kHz 错峰运行。
2. **PWM 同步提交与 T 型换相缺板上证据。** 目前 CMP 使用 ZERO 影子装载，配置表所称全局加载仍未启用。AQ force 与 CMP 更新跨周期的换相瞬态，必须在四个门极逐一测量；尤其要验证正/负半周过零、0%/最大占空比与 ISR 延迟。
3. **BUS 缺专属硬件故障输入。** ePWM8 的互补死区会使 AQ A 强制低时 B 可能为高；当前在启动时单独锁存 ePWM8 的 TZ OST，确保两路门极保持低。保护表尚未给它配置独立过流/母线过压 TZ 来源；必须确认硬件比较器输出、电平极性与作用范围后接入，不应猜测。
4. **应用控制策略仍是骨架。** 离网电压环+半母线前馈+重复控制或电压外环电流内环、并网电流环+电网前馈+重复控制均未实现。PV 继承的 PI 参数、各保护阈值、INV RMS 幅值环均需基于真实 L/C、采样比例和延时重新整定。并网自动合闸已锁禁。
5. **通信未完成端到端验证。** SCI 环形缓存的帧所有权、错误后恢复、CAN 发送邮箱忙和 Modbus 32 位跨寄存器写入的原子性仍需修复/测试；修正寄存器配置不等于协议已正常通信。
6. **无法在无控制板条件下证明实际运行。** 必须用隔离供电、驱动禁止、低压直流源和示波器/JTAG 依照 `03_validation_plan.md` 分阶段验证。需特别测 ZERO/PRD ADC EOC、CLA1_1 周期与 CPU 占用、保护传播延时和复位后的安全态，达标后才能允许真实功率级使能。
