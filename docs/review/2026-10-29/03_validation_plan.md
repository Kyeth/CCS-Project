# 底层重构边界与验证方案

本文是基于审阅结论的实施和验收规格，不表示这些修复已写入固件或已通过实板测试。用户给定GPIO保持为设计输入；所有保护阈值、驱动极性、滤波和环路参数应有明确来源。

## 1. 分层落地

| 层 | 应负责 | 不应承担 |
|---|---|---|
| Broad | 时钟、外设实例、每ADC的16个SOC、PWM同步路由、开关映射、保护极性/源选择/动作表、静态配置校验 | 状态机策略、控制算法、Modbus业务变量指针 |
| Drivers | F28374S寄存器实现、初始化状态、原子数据搬移、硬件启停/锁存、错误码、实际频率/时间返回 | 电压电流业务解释、应用发波条件、外部组件状态机 |
| Platform | Sampling、PwmBridge、Safety、通信帧、CRC、FRAM参数事务、时间戳、调度/健康监视 | 自动并网、目标电压/功率和MPPT策略 |
| User_App | 最小诊断应用；底层通过后才添加离/并网控制与整机状态机 | 直接改寄存器或依赖驱动隐藏状态 |

Broad名称可以继续保留，是否改为Board是命名选择，不是修复前置条件。硬件表与应用组合根分开：`main`负责把CLA入口、协议表、组件回调连接到对应层；不要让通用驱动include User_App。

删除旧User_App前需要迁移：InterruptCfg、CLA Task/共享结构、基础采样标定、时基调度、WatchDog、安全故障执行。CLA是采样组件的执行后端，底层仍需要它。旧状态机与控制算法可暂时从构建排除并归档为参考，避免同时运行两套初始化。

## 2. 推荐接口契约

### 配置

ADC使用 `adc[module].soc[16]`，每项带enabled/trigger/channel/acquisition_ns，初始化前计算ACQPS并校验范围。采样计划另外描述batch、result_slot、owner、timestamp、completed_by，避免以编号约定代替完成条件。

X-BAR项必须分别包含 input GPIO、mux index、source selector、enable、最终极性、fault_id；TZ表包含作用PWM集合、A/B动作、CBC/OST、同步/异步模式、恢复权限。校验重复资源和未接保护的功率输出。

PWM表以目标Hz/计数模式/相位表达，转换后提供实际频率；同步源只能使用本芯片可达路由。明确CMP/AQ/DB装载事件和每组commit主模块，禁止在底层函数中无条件覆盖Broad选择。

### 功率输出

至少区分以下状态和动作：

| 动作 | 含义 | 能否自动恢复 |
|---|---|---|
| DisableGate | 外部驱动禁止，输出置定义安全态 | 仅通过显式Arm |
| NeutralClamp | T型中点钳位，S2/S3导通 | 正常调制流程可切换 |
| StageDuty | 写下周期命令及极性，不宣称已经生效 | 不改变锁存故障 |
| CommitAtBoundary | 在已定义载波边界统一提交 | 需时序有效且Ready |
| TripLatch | 由硬件/软件故障锁存禁用相关功率级 | 仅受控FaultReset |

组件返回requested与active状态/序号，拒绝NaN、越界以及未知配置。故障执行优先于任何请求，应用不得直接清TZ绕过安全层。

### 采样发布

CPU→CLA只由CPU写，CLA→CPU只由CLA写；结构使用固定宽度字段并检查sizeof/offsetof。输出需含sample_seq、batch有效位、MUX地址及年龄、ADC溢出、CLA溢出/漏任务计数。快环只消费一致快照。未完成校准、数据过期或无第二样本时不能伪装为有效零电流。

## 3. 启动顺序规格

1. 禁止外部驱动，DINT；配置系统时钟并记录实际SYSCLK/EPWMCLK/LSPCLK。
2. TBCLKSYNC保持0，关闭SOC/任务触发；设置GPIO安全电平、X-BAR、TZ及输出锁存。
3. 配置PWM时基/相位/AQ/DB/影子/同步；不解除功率禁止。
4. 配置ADC电源、分辨率/校准、SOC、优先级和INT；等待上电稳定。
5. 初始化CPU组件、标定状态、协议、调度和故障存储；CPU先完成CLA数据初始化，再配置LS所有权/程序用途和消息RAM；复制CLA程序、设MVECT与触发源，校验所有等待结果。
6. 只清允许清除的ADC/CLA/PIE待决标志，保留故障锁存；注册与开放需要的中断。
7. 启动独立健康监视计时器，统一启动PWM时基和采样链，EINT。外部驱动仍禁止。
8. 收集连续有效样本并检查序列、频率、任务完成时间、无overflow，再置SamplingReady。功率Arm是后续独立操作。

## 4. 修复后的目标链路时序

20 kHz周期50µs，ZERO/PRD间隔25µs。SOC采样窗按SYSCLK计算，ADC转换时间按器件分辨率/ADCCLK计算，两者不要混用。

```text
t = 0                 ZERO → SOCA → 四ADC第一批（各ADC内部确定顺序）
t = Tzero_done        确认第一批全部完成 → CLA Task1 → CPU ISR
t = 25 us             PRD → SOCB → A8/A9、D8/D9
t = 25 + Tprd_done    确认第二批完成 → CLA Task2 → 发布第二样本
t = 50 us             下一ZERO，加载已提交PWM命令，重复上述过程
```

若在ZERO后ISR写入ZERO装载影子，默认下一ZERO才生效，应计入接近一周期的控制延迟。不得在论文/环路模型中当作立即生效。Task1/Task2使用同一CLA，需证明它们的最坏执行与等待不会互相挤占下一截止期。增加任务耗时和overflow监视，而不是仅累计“进过ISR”。

跨ADC完成屏障需列出实际每SOC起止时刻。修复stride和优先级后，重新计算A15/A9是否确实晚于其他模块最后有效结果；当前代码没有提供这一证明。相间电流串行采样偏移应计入控制误差。

## 5. 分阶段验收矩阵

### 阶段A：静态/构建，不接功率

| ID | 操作 | 必须保存的证据/通过标准 |
|---|---|---|
| A01 | 冻结工具链、ABI、优化和器件宏，干净构建 | 零编译/链接错误，map和配置版本一致 |
| A02 | 检查链接消息段/CLA程序/数据/栈 | 0x1480 CLA→CPU、0x1500 CPU→CLA，无重叠；段大小在RAM容量内 |
| A03 | 配置验证器重放ADC/X-BAR/PWM表 | 全部实际字段与批准配置一致；无保留寄存器写入 |
| A04 | CRC、环形缓冲、帧队列、参数事务测试 | 标准向量通过；满缓冲/跨界/回绕/背靠背帧不破坏边界 |
| A05 | 输入异常配置 | 初始化失败返回明确错误，外部驱动保持禁止 |

当前已完成的是原始基线构建、ADC静态对照及数值/CRC检查，不是修复后A01–A05全部通过。

### 阶段B：控制板供电，驱动禁止

| ID | 操作 | 通过标准 |
|---|---|---|
| B01 | CPU token→CLA响应最小任务 | seq持续递增，内容和写入方向正确，冷启动一致 |
| B02 | 单独PWM触发单ADC单SOC，逐步扩展 | RESULT变化、EOC/CLA/ISR计数匹配，频率实测20kHz |
| B03 | 注入各ADC不同已知电压 | 逐项RESULT/通道正确，物理量增益与极性一致 |
| B04 | ZERO/PRD交替，完整运行四ADC | 两批可区分，Task2读8/9；Task1只读完成批次，无跨批混用 |
| B05 | 记录TBCTR、SOC/EOC、CLA/CPU时刻 | 50µs周期与25µs分隔符合误差预算，无overflow/任务堆积 |
| B06 | 六MUX地址逐一稳定电压输入 | 地址标签与物理量一致，首次切换和模拟建立时间合格 |
| B07 | 停SOCA/停CLA/停PIE/停后台 | 独立超时机制触发禁止与锁存，恢复受控 |

建议调试观察：`ADCSOCxCTL`、`ADCSOCPRIORITYCTL/RRPOINTER`、`ADCINTSEL/FLG/OVF`、`CLA1TASKSRCSEL`、`MVECT1/2`、`MIER/MIFR/MIRUN/MIOVF`、消息seq、`PIEIER11/PIEIFR11`、CPU IER/IFR/INTM、Timer计数。禁止只靠观察单一MIFR位判断CLA是否执行。

### 阶段C：通信与存储

| ID | 操作 | 通过标准 |
|---|---|---|
| C01 | SCI 1…最大长度及各种尾包 | FIFO与软件收到字节数一致，帧边界正确 |
| C02 | 注入FE/PE/OE/break及ring overflow | 错误帧不执行命令，下一合法帧恢复；计数可追踪 |
| C03 | Modbus03/06/10、未支持04，非法地址/长度/CRC、宽值字序 | 合法报文正确响应，未支持功能明确拒绝，非法报文不修改控制参数；读写回显含实际应用结果 |
| C04 | CANA标准0x123，CANB扩展ID，满载/无ACK | 分析仪ID正确，丢包/邮箱忙/总线错误明确上报 |
| C05 | SPI已知字节、多字符CS、超时 | 字节位序与CPOL/CPHA一致，0xA5不会被右移成0 |
| C06 | FRAM DATA/HEADER期间新写参数与逐片掉电 | 不丢最新dirty，启动只采用完整有效版本 |
| C07 | I2C时序、NACK、SDA/SCL卡低 | 不无限阻塞，恢复有界，控制链不受影响 |

### 阶段D：无高压母线，门极/保护波形

先验证故障全关，再验证正常发波。此阶段观测DSP输出与外部门极驱动两侧，不能只看DSP引脚。

| ID | 操作 | 通过标准 |
|---|---|---|
| D01 | 每路故障单独注入，包含低有效组合四种情况 | 作用对象正确，全部要求输出进入定义安全态，延时满足硬件预算 |
| D02 | 观察INV六模块和PV四相 | INV同相位；PV交错可重复；INV/PV/BUS统一实测20kHz |
| D03 | 正半周/负半周，d=0/小值/0.5/允许最大值 | 满足01文档真值表，死区为批准值，无非法组合 |
| D04 | 过零换相、命令邻近装载边界、插入ISR延迟 | 没有竖管危险同时导通，钳位/释放顺序确定 |
| D05 | Init→Enable、Stop→Enable、Trip→Reset | 同/异半周恢复都正确，Trip不能被普通SetDuty解除 |
| D06 | BUS Disable/Neutral/Run及PV停止 | BUS禁止时双输出安全；PV停止无残余窄脉冲 |
| D07 | 调试暂停、断线、复位/看门狗复位 | 外部门极保持规定安全态，重新启动不自动授权功率 |

### 阶段E：低压限流功率测试，再设计闭环

仅在前述阶段有证据通过后：先低压限流单相与假负载，确认电流方向、器件换流、采样增益/相位和保护延迟；再三相。离网控制先选定电压单环或电压外环电流内环，建立含PWM更新、ADC/CLA和滤波延迟的离散模型；并网先验证电流调节与同步许可，最后增加前馈/重复控制。不要同时启动INV/PV/BUS全部闭环后再定位底层。

## 6. 尚需从硬件/设计取得的数据

这些缺失不影响已确认配置缺陷的修复，但决定功率试验和闭环参数：滤波L/C与阻尼、额定/最大母线与输出范围、采样前端R/C和增益/零点、驱动使能与故障极性、MOS与驱动传播延时、保护比较器阈值和响应时间、过流/短路/过压动作范围、ATS/TVS实际协议和同步许可来源、Bootloader入口/版本契约。

每个修复提交应附：改动配置、寄存器读回、对应测试ID、波形/日志、通过标准及未解决项。未执行的实板测试明确标记“未测”，不能以静态分析结果替代。
